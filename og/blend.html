For the grown-up

In Read it mode, ask for the sounds first, then the whole word — never the other way round. If a word needs more than one attempt, put it back in the pile and come to it again tomorrow. In Build it mode the word is spoken but hidden: that is spelling from dictation, which is harder than reading, so expect to drop back a set or two.
